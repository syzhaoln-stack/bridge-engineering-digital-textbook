# 车辆资产来源

Kenney Car Kit 3.1 的 delivery 模型（CC0）。
来源：https://kenney.nl/assets/car-kit
下载日期：2026-09-05。原始 OBJ、MTL、纹理及许可随附。

转换脚本：scripts/convert_kenney_vehicle.py。将调色板烘焙到顶点颜色，离线页面无需请求模型文件。演示按教学轮距、轴距缩放车体，并把四轮放在求解使用的接触区中心；车轮随放大的板位移显示，未计算悬架或车辆动力。车辆外形不代表规范荷载车辆。

2026-09-05 尺寸修订：车辆采用统一 1.8 倍缩放，不再分别拉伸三个方向。所得轮距 1.62 m、轴距 2.916 m；两者为教学设置。主梁间距 2.40 m、板厚 0.220 m 采用教材第4章的板带算例参数。
