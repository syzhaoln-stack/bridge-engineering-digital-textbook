物理参数

模型范围与结果一致性

三维坐标由同一节点表与位移表生成，板跨向 x、板宽方向 y、竖向 z（小车场景的 y 沿主梁方向）；展示映射至 Three.js 的 (x,z,−y)。显示变形为 z=放大倍数×w。旋转和缩放只改变相机。点击节点、方向视图、数字读数与题目核对均引用当前结果；网格与求解版本写入导出记录。节点位移着色采用插值显示，不是应力图。求解在本地 Web Worker 执行。
