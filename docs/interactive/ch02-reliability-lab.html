结果解释

可靠指标与失效概率

可靠度由均值差和随机变量的离散程度共同决定。

平均抗力大于平均作用效应只反映两个分布中心的相对位置；分布尾部仍可能进入失效域。离散程度增大时，越过极限状态边界的概率质量可能增加，因此应同时考察均值、标准差与相关性。

同一分析框架可用于其他“能力—需求”问题，但其概率分布、相关性和越界后果必须依据相应对象重新确定。

保持均值不变时，增大标准差会加宽分布，并改变越过极限状态边界的概率质量。

Z = R − SσZ = √(σR² + σS² − 2ρσRσS)β = (μR − μS) / σZPf = Φ(−β)

初始情形取 ρ = 0，R 与 S 相互独立，所以 σZ = √(σR² + σS²)。“可靠指标 β”就是均值差里能放下多少个“差值的标准差”；Pf 是 Z < 0 的理论概率。
