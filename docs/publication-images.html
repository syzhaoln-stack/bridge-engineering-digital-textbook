公开预览中放了什么

本预览保留教材正文、自制静态图、交互与动画，以及随附许可的程序依赖。Kenney配送车属于一个第三方CC0模型，OBJ、材质和贴图不算成多张教材插图，许可随模型保留。

原始参考教材裁图、网络候选图片、作者筛图工具和申报材料没有装入公开包。正文原参考图位置保留图题和说明；本地内部审稿版仍可查看原候选。Commons上可能有可合规使用的开放图片，但本轮登记的许可线索还需逐图回查，未整库直接转载。

全书的文字与教学设计也参考了教材、标准和公开课程，分别在参考文献、外部课程导读和旧版接续说明中列明。外部来源是参考依据，不表示对方审定或认可了本教材。

正式成书，先按约300幅独立成图做预算

AI能不能把图统一成一种风格

可以辅助统一构图、配色、字体、箭头和图解层次。对于受力图与工程构造图，更适合让AI协助写绘图脚本，由尺寸、连接和计算结果控制几何与数值，再人工审图。这样同一套数据可以输出静态矢量图，也能进入交互。

把某张原图改色、描摹或交给AI换画风，并不会自动取得原作的复制和改编权。独立绘图要从原理、可用数据和自己的设计说明出发，保留制作过程。AI改变桥形或构件后的画面应标教学示意，不能作为某座实桥的纪实照片。国家版权局：著作权法

工程图能不能重建成CAD

可以，但要分输入。自有或获许可的DWG/DXF，可统一图层、线型、标注和版式；只有扫描图时，需先识别尺寸、轴线、构件、连接和图例，再按约束重建。自动描线得到的轮廓不能代替带单位、比例和工程含义的图纸。

本项目适合先从简支梁、梁格横断面或已知尺寸的构造图开始：写清参数 → 生成CAD/SVG → 核对尺寸与力的方向 → 导出出版矢量图 → 在最终版面复核。这里是后续制图路线，新版尚未完成AI绘CAD教学单元，所以不把它列为已实现章节或资源。 已有空间投影工作台用于三视图认知，不等于已实现这条流程。

每张图最后要留下什么

至少登记：本书图号与用途、作者和出处、数据或尺寸依据、许可与改动方式、可编辑源文件、输出版本、技术复核人、最终采用状态。先做一个完整样章的成图与试排，再将通过的规则用于全书。
