三、受控提示词与计算助手

使用AI协助学习时，写清任务、已知条件、单位、假设、所需输出、检查方法，以及哪些缺失信息不能猜测。可以按下面四类任务提出要求：

  1. 概念解释模板：要求指出真实构件、理想模型、荷载路径、核心关系和适用边界；
  2. 公式与程序模板：要求逐一定义符号和单位，保留公式来源，输出可复算数据并进行量纲、平衡和极限情况检查；
  3. 模型审查模板：输入单元、材料、截面、连接、边界、作用、施工阶段和目标响应，输出缺失项、异常项及验证方案；
  4. 图表说明模板：读取原始数据和绘图脚本，说明坐标、量纲、参数范围、图形所支持的结论及不可外推范围。

所有工具输出均作为待核材料。规范系数、工程参数、桥梁事故事实和设计结论应回查原始文件并由教师或设计责任人确认；提示词、模型版本和人工修改记录随作业或案例一并提交。

四、从三维外形走到计算模型

先打开模型层级实验，比较外形、构件和计算模型分别保留了什么。自己建模时，先识别桥型和构件，再列尺寸与连接条件。按桥向\(x\)、横桥向\(y\)、竖向\(z\)记录坐标；显示软件使用不同坐标时，写清转换关系，再核对导出的坐标。

检查模型时，把参数表、荷载路径、构件分组和节点—单元表放在一起，查找重复节点与孤立构件。OBJ外形模型、STL打印网格和有限元模型服务于不同目的；外形看起来相同，不代表连接、约束和受力也相同。使用Bridge Modeler等建模工具时，同样需要核对这些输入与输出，另行完成结构计算和适用的规范验算。

五、使用结构分析软件时，先检查什么？

在MIDAS或同类软件中练习时，可以依次检查以下内容。这是一份建模检查顺序，不是视频播放目录：

  1. 单位、坐标、材料与截面的建立及手算抽查；
  2. 节点、单元、偏置、连接和支承自由度的检查；
  3. 自重、二期恒载、温度、预应力和基础位移等基本工况；
  4. 移动荷载、影响线、车道与控制截面；
  5. 施工阶段激活、合龙、张拉及体系转换；
  6. 组合、包络、目标响应与结果导出；
  7. 平衡、闭式解、网格趋势、独立模型和运行日志；
  8. 参数批处理、版本差异与复核报告。

记录软件版本、单位制、所用规范模块和模型输入。得到结果后，至少用一个手算关系或独立模型核对；仅保存软件截图还不足以让别人复算。
