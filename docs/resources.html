三、受控提示词与计算助手

提示词按“任务—已知—单位—假定—输出—校核—禁止补全项”七个字段组织。教材提供四类模板：

  1. 概念解释模板：要求指出真实构件、理想模型、荷载路径、核心关系和适用边界；
  2. 公式与程序模板：要求逐一定义符号和单位，保留公式来源，输出可复算数据并进行量纲、平衡和极限情况检查；
  3. 模型审查模板：输入单元、材料、截面、连接、边界、作用、施工阶段和目标响应，输出缺失项、异常项及验证方案；
  4. 图表说明模板：读取原始数据和绘图脚本，说明坐标、量纲、参数范围、图形所支持的结论及不可外推范围。

所有工具输出均作为待核材料。规范系数、工程参数、桥梁事故事实和设计结论应回查原始文件并由教师或设计责任人确认；提示词、模型版本和人工修改记录随作业或案例一并提交。

四、Bridge Modeler Skill

Bridge Modeler Skill把桥型识别、构件分解、坐标约定、参数契约、几何重建、交互显示与节点—单元导出组织为可复用流程。课程统一采用桥向\(x\)、横桥向\(y\)、竖向\(z\)；三维显示程序通过唯一转换函数映射到图形坐标，工程坐标和导出坐标保持不变。

Skill的典型成果包括：参数表、荷载路径图、可旋转三维模型、构件分组、节点—单元表、重复节点与孤立构件检查、OBJ视觉模型和STL打印前检查。教学几何、打印网格和有限元模型具有不同对象边界，分别验证。该Skill用于形成可检查模型和建模记录，不代替结构分析、规范验算与工程签认。

五、MIDAS及同类软件视频

课程组录屏建议按可核查任务拆分为下列资源包：

  1. 单位、坐标、材料与截面的建立及手算抽查；
  2. 节点、单元、偏置、连接和支承自由度的检查；
  3. 自重、二期恒载、温度、预应力和基础位移等基本工况；
  4. 移动荷载、影响线、车道与控制截面；
  5. 施工阶段激活、合龙、张拉及体系转换；
  6. 组合、包络、目标响应与结果导出；
  7. 平衡、闭式解、网格趋势、独立模型和运行日志；
  8. 参数批处理、版本差异与复核报告。

每段视频开头显示输入与分析目标，结尾显示校核证据；软件名称、版本、单位制、规范模块和模型文件随视频登记。软件界面和商标按许可使用，教材正文采用工具中立的流程图和课程组自有模型。
