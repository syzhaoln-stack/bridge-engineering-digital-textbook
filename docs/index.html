前言

《桥梁工程智能设计——体系分析、交互可视化与数字建模》面向土木工程、道路桥梁与渡河工程等专业的桥梁工程课程。教材以桥梁体系、荷载路径、作用组合和极限状态为知识主线，以参数化模型、交互图形和工程计算模型为数字化载体，服务于56学时的课堂教学、课内实践与课程设计。

本教材所称“智能设计”，主要指三类可核查的教学活动：一是把桥型、构造、边界条件和荷载路径表示为可操作的参数模型；二是把公式中的变量、图形中的几何量和计算结果建立同步映射；三是利用人工智能辅助检索、建模、编程和结果复核，但工程结论仍由规范条文、力学原理和可追溯计算共同约束。

使用方式

全书采用“HTML主版本＋PDF配套版本”的双版本结构。HTML版本承载三维模型、参数滑块、影响线加载、概率分布和计算过程；PDF版本用于审阅、印刷与长期归档，保留相同编号的关键状态图、公式、数据表以及进入交互资源的链接或二维码。PDF阅读器对脚本和三维模型的支持不一致，因此不把PDF内嵌脚本作为主要实现方式。

从核心思维开始　每章10组视频与交互　跨课程并排类比

本分支先呈现各章的核心问题与学习任务，完整参考内容可随时切换。新增110个编号单元，每章10组；每组配短视频、计算代码、操作实验与形成性自测。另保留原专题实验与早期样片供比较和继续完善。

每个数字实验均按以下顺序组织：

  1. 明确工程对象和学习目标；
  2. 给出基本假定、变量、单位和计算公式；
  3. 改变一个或一组有明确含义的参数；
  4. 同步观察构造、受力或性能指标；
  5. 保存关键状态并解释适用范围。

数字资源配置

  1. 交互网站。 配置桥型三维图谱、结构概念实验、作用组合瀑布图、可靠度联合分布、影响线移动加载、桥型参数实验、风致现象和有限元模型层级等页面；参数、公式、图形和结果同步更新。
  2. 提示词与计算模板。 按任务、已知数据、单位、假定、输出、校核和待确认项组织，用于资料检索、公式程序化、模型审查和图表说明，并保留人工复核记录。
  3. Bridge Modeler Skill。 将桥型识别、构件分解、坐标、参数契约、三维重建、节点—单元导出和拓扑检查固化为可重复使用的建模流程。
  4. 教学视频与模型包。 Manim概念动画用于解释力流、尺度、作用、桥型、专项性能和有限元模型层级；MIDAS类软件录屏用于演示单位坐标、材料截面、连接边界、作用、移动荷载、施工阶段、组合、结果提取和验证流程。视频均随附分镜或操作单、模型文件、版本和检查表。

资源入口、稳定文件标识和使用边界见数字资源索引。

课程边界。 本教材讲清桥梁体系如何选、荷载如何传、计算模型如何建、结果如何用于设计判断。《材料力学》提供应力、变形、弯曲、剪切、扭转和稳定的基本关系，《结构设计原理》提供材料本构、截面抗力、裂缝、疲劳和极限状态验算；本书在每章给出二者与桥梁总体设计的输入、输出和规范接口，并通过桥梁算例完成综合应用。

每个章节均按“先识别材料力学关系，再形成桥梁总体效应，最后进入结构设计原理验算”的次序组织。这样既避免重复两门先修课程的全部推导，也避免桥梁课程只给软件结果而失去力学解释。
