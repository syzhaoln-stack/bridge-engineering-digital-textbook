## 三种画法怎样组成一本书

共同保持浅底、清楚轮廓、完整构件、克制的色彩和留白。根据内容选择画法，不把全书机械地改成一种渲染效果。

- **空间关系、生活教具和施工过程：三维教具。** 参照 G01-B、G02-B、G04-B。柔和光照，灰色结构，少量黄色车辆或橙色施工构件；不堆水面、植物和建筑。每张图只突出一个关系。
- **梁底、基础、材料病害：写实细部。** 参照 G03-A、G07-A、G08-A。纹理帮助辨认材料与连接，避免粗糙纹理盖住边缘。基础可剖去土体，但明确属于观察方法，不能把桩画成实际悬空。
- **大跨桥整体：线稿淡彩。** 参照 G05-C、G06-C。先保证塔、索、锚点和桥面连接正确，再加细线和淡彩；一张图的索线必须能逐根追踪到端点，不能用交叉装饰线掩盖连接。

## 后续制图的执行次序

1. 先确定本图是哪个算例。核对跨度、桥宽、梁距、截面、桩数、车辆外廓及单位；来源不足的值标为教学约定。
2. 需要构造准确的图先用 Blender、CAD、SVG 或 Python 建立可核对的几何；同一案例各视角从同一模型导出。
3. 按本表选定的画法处理材质、光照、底色和线条。风格参考不代替结构参考。
4. 核对生成结果和几何底稿：支承是否真正接触、索是否接到正确位置、构件数量和比例是否一致、有没有裁掉需要观察的部分。
5. 中文标签、尺寸及力的箭头另用矢量层绘制。标签箭头与力箭头分别说明；只有计算结果才能标数值或绘应力图。
6. 正文先给学生一个可观察的问题。尺寸合同、程序、来源及制作说明放在展开区；保留印刷用静态图和网页用交互入口。

新增 Blender 案例为 3×30 m 双幅 T 梁桥，每幅 12.50 m、每跨5梁，单个中墩承台下6桩。它可提供 G03、G07 方向的新图，但不能直接冠以原 20 m 五梁算例或八桩案例的尺寸和编号。若采用新案例，应同时换图号、图注和相关计算条件。
