# 把搁板放大一倍，为什么不是重一倍？

小周：一块搁板不够大，我照着原样放大一倍。料多用一倍，总该够了吧？

阿宁：你说的放大，是只加长，还是长、宽、厚全都变成两倍？先拿两个盒子比一下。

小周：全都两倍嘛，模样还一样。等等，这里面，能塞进去八个小盒子？

阿宁：对。同样材料，体积变成八倍，自重也变成八倍。这只是重量，还不是它弯得怎样。

小周：那它也变厚、变宽了，扛弯的本事肯定跟着涨。是不是正好抵消？

阿宁：在这根只受自重的简支梁里，并没有抵消。按相同比例放大后，弯曲应力变成两倍，下沉量变成四倍。前提是材料相同，而且仍能用线弹性小变形来算。

小周：我家的搁板一般不变厚，只是两个支架离远了。那还能套刚才的四倍吗？

阿宁：不能。若截面和每米荷载不变，只把跨度加倍，下沉量会变成十六倍。你换了放大的方式，比较的就已经是另一个问题。

小周：那问大桥有没有尺度问题，得先问到底什么变大、什么没变，不能只盯着长度。

阿宁：是。先说清缩放条件，再看长度、面积、体积和响应各按什么比例变化。这种比较方法，叫尺度分析。
