# 出版图片授权、AI重绘与CAD重建

核查日期：2026-09-06。用途：本教材纸质版、PDF、配套网页及公众课程的选图与制作。以下流程是项目实施建议；本轮核查了官方法律、许可说明与工具文档，**没有逐张确认现有候选图的出版授权，也未安装工具或下载媒体**。

AI辅助绘CAD在本文中仅作为后续出版制图路线。**本轮未实际建立该工作流或教学单元，暂不写成教材正文中的已实现能力，也不计入现有数字资源数量。** 独立仓库中的制图规范可在后续实际完成、复核之后再形成教学案例。

## 1. 三个问题的直接结论

| 想做的事 | 可采取的路径 | 进入出版稿前要确认 |
|---|---|---|
| 沿用Google搜到的图 | 回到原发布页，按许可原图使用，或向权利人取得所需用途授权 | 搜索结果不是授权书；原图作者、许可版本、用途和署名清楚 |
| 用AI统一风格重绘 | 已获改编许可的图可按许可改编；力学知识优先从文字问题、公式、尺寸与自有数据独立制图 | 换风格不等于权利清零；生成图还要核查科学性、输入权利及工具条款 |
| 将工程图重建为CAD | 自有或获许可原图可转矢量、按尺寸重建；通用力学模型可独立参数化绘图 | 格式转换不替代授权，CAD线条也不自动具有正确尺寸、连接和工程语义 |

**本书建议采用的组合：真实照片负责“看见桥”，数据驱动的SVG/TikZ/CAD负责“看懂结构”，AI示意插画负责辅助情境。** 三者分别制作和验收，不用一种工具包办所有图片。

## 2. 原理可以借鉴，图的表达要另看

WIPO明确区分思想、原理、方法、数学概念与其具体表达。受力平衡原理可用于新的教学图，但讲解它的独特示意图、文字和构图不因此变成自由素材。[WIPO：著作权保护什么](https://www.wipo.int/en/web/copyright/protection)

中国《著作权法》第三条包括摄影、工程设计图、示意图等作品；第五条列有单纯事实消息、通用数表和公式等不适用对象。第十三、十六条说明，改编形成新表达仍须处理原作品权利。持有图片、书本或DWG文件，也不能直接推定拥有出版许可。[国家版权局：著作权法，第三、五、十三、十六、二十条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

据此，本项目采用下面的编辑判断，具体作品有争议时交出版社复核：

| 制作方式 | 本项目如何记录 |
|---|---|
| 对原图改色、换字体、描轮廓、AI换画风，保留原图构图与特有表达 | 记录原作品与改动；按复制/改编用途核权，不能标“完全原创” |
| 根据公开的桥长、桥宽和结构原理，重新确定视角、对象取舍、图解顺序与标注，自行计算并出图 | 保存数据来源、草图、参数及脚本，标“据相关资料独立绘制”；仍检查是否复制了原图表达 |
| 从多本书取同一知识点，再拼接或略改几幅原图 | 逐一记录组成来源；来源变多并不自动成为独立创作 |
| 只做必要的格式或分辨率转换 | 仍沿用原作品授权条件；是否构成改编与具体修改有关，不能仅按文件扩展名判断 |

课堂使用与出版使用分开：《著作权法》第二十四条的课堂教学条款不允许据此出版发行；适当引用也有目的与范围条件。第二十五条另有特定教科书法定许可及付酬要求，不能只因本书叫“教材”就直接套用。拟走法定许可的图，先由出版社确认适用条件与手续。[同法第二十四、二十五条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

## 3. Google、CC与Wikimedia怎样用于选图

Google说明，“使用权限”依赖图片提供方或所在网站给出的信息，并建议再次核对许可详情。操作上保留**原发布页和许可页**，不要只留Google结果页、缩略图链接或“搜得到”这一条证据。[Google图片使用权帮助](https://support.google.com/websearch/answer/29508?co=GENIE.Platform%3DDesktop&hl=en)

以下以CC 4.0为例。旧版、地域版或多重许可须按该张图实际声明处理。

| 标识 | 原图放入商业出版物 | 统一风格后发布 | 本项目处理 |
|---|---|---|---|
| CC BY | 通常允许，遵守署名等条件 | 允许，说明改动 | 保留作者、原出处、许可链接和改动说明。[BY](https://creativecommons.org/licenses/by/4.0/deed.zh-hans) |
| CC BY-SA | 通常允许，遵守署名等条件 | 允许；演绎作品按相同或兼容许可分享 | 将改编图及许可明确标出；不对该图附加与许可冲突的限制。[BY-SA](https://creativecommons.org/licenses/by-sa/4.0/deed.zh-hans) |
| CC BY-NC及含NC的组合 | NC不授予商业用途；商业教材应另取得相应许可 | 改编也不能绕开NC | 不因“教育用途”或免费网页就默认满足NC；核对具体使用目的。[BY-NC](https://creativecommons.org/licenses/by-nc/4.0/deed.zh-hans) |
| CC BY-ND及含ND的组合 | BY-ND可在不分享演绎作品并满足其他条款时使用；如另含NC，还受NC约束 | ND不允许公开分享演绎版本 | AI换风格后拟出版，走另行授权或改选素材；必要技术格式修改不当然属于演绎。[ND法律文本](https://creativecommons.org/licenses/by-nd/4.0/legalcode.zh-hans) |
| CC0 | 可依其权利放弃/许可安排使用 | 通常可修改并商用 | 核实声明者有权作声明；仍留出处，另看肖像、商标等未涵盖权利。[CC0](https://creativecommons.org/publicdomain/zero/1.0/deed.zh-hans) |
| 公有领域 | 核实其成立原因与本次使用地区后处理 | 不受已届满的相关财产权限制，但不能据此忽略其他权利 | 不把“年代久”“政府网站有图”“美国标PD”直接等同于本项目可全球任意使用 |

**SA通常针对演绎作品，不因一张图出现在书里就自动要求全书采用同一许可。** 但图及其演绎部分的条件仍需遵守；把图改造成与其他内容不可分的整体时，应具体判断，不能一概按独立汇编处理。[CC关于SA与汇编的说明](https://wiki.creativecommons.org/wiki/ShareAlike_interpretation)

Wikimedia Commons可作为优先图源，但应打开每个文件的说明页核对作者、原来源、许可与版本；上传者未必是作者，维基项目的正文许可也未必就是图片许可。Commons不保证每个文件的权利标注都准确。[Commons站外复用指南](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en)

可直接使用的图注结构：

> 图4-×　【本书图题】。原作：【作者／机构】，《【原题】》，【原发布链接】，CC BY 4.0【许可链接】；课程组调整配色与中文标注，2026。【适用时补充：教学示意／尺寸依据／变形放大倍数。】

这只是填写模板，不能保留空字段或把示例许可贴到不具备该许可的图上。仅写“图片来自网络”不能支持出版核权。

## 4. AI统一风格：怎样做才有用

AI可以帮助提出构图、试配色、整理图解层次、生成情境草图，也可辅助编写SVG或CAD脚本。对已有图片输入AI修改，先查输入和改编权限；对独立生成图，保存文字需求、参数来源与人工修改过程，再检查输出是否近似复现特定作品。

不能把“模型训练来源已有安排”“工具允许某类商用”“输出在合同中归用户”“输出一定受著作权保护且不侵害第三方”合成一句话。它们处理不同问题。**本项目不承诺任何AI工具能使全部权利自动清零。**

一个可核实的条款例子是Adobe：其2026-04-23产品条款要求输入具有足够权利，用户负责输出使用，并指出输出可能不独特、可能不受知识产权保护；赔偿安排只适用指定计划及条件。2026-05-15使用指南另要求尊重第三方权利、保留Content Credentials。这仅说明需要检查条款，不是本项目已购买相应保障或所有AI工具适用同样条件。[Adobe产品条款](https://www.adobe.com/cc-shared/assets/pdf/legal/servicetou/adobe-generative-ai-product-specific-terms-en-us-20260423.pdf)、[Adobe使用指南](https://www.adobe.com/legal/licenses-terms/adobe-gen-ai-user-guidelines.html)

本项目操作约定：

1. **统一视觉规则，保留工程参数。** 在自有模板中固定颜色、线宽、字体、箭头、荷载与位移的区分；不要把尺寸、公式、轮距和支承关系交给图像模型自由改写。
2. **从知识说明生成，比照原图描摹更适合原理图。** 例如输入“5根等间距主梁、给定梁距和荷载位置，显示各梁分担”，由计算脚本出数和几何，再做版式。独立绘制的判断仍看实际过程与表达，不能只靠提示词声明。
3. **实桥照片保持纪实身份。** 作为某座桥现状证据的图使用可核实照片；AI补建构件、替换背景或改变桥形后，改标“AI辅助教学示意/概念图”，不以“某桥实景”使用。一般曝光调整与改变事实内容分开记录。
4. **训练或微调另列用途。** 本流程的参考图编辑不包含训练授权；若以后收集教材插图训练统一风格模型，重新核对素材许可、平台条款与用途，不能把出版许可直接当作训练许可。

## 5. CAD重建：优先恢复尺寸与结构关系

Autodesk的Raster Design提供光栅转矢量与文字转换相关工具，官方教程展示从光栅数据建立矢量基本图元。它解决线与文字的转化，不证明输出已经是尺寸正确的工程模型。[Autodesk光栅转矢量说明](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/How-to-vectorize-raster-files-to-vector-data-in-Raster-Design.html)、[官方矢量化教程](https://www.autodesk.com/learn/ondemand/curated/autocad-raster-design/6Ey9TnSWyHOQiggwYVu6Mw)

建议将任务区分为两类：

- **保真整理原工程图：** 以获许可的原DWG、矢量PDF或清晰扫描为依据，保留原作者与工程身份；先校正比例和尺寸，再整理图层、线型、文字及标注。转换或清理后仍记录原图，不改称自有设计。
- **为教材独立重建图解：** 从已核实的尺寸表、剖面、材料与构件关系建模；明确教学取舍，重新设计视图和标注；输出与互动场景使用同一份参数。原图特有表达是否仍被沿用，另作核查。

本书拟用的生产步骤如下，属于工程制图质量约定：

| 步骤 | 要做什么 | 交付检查 |
|---|---|---|
| 定义图的用途 | 解释传力、显示构造，还是供量尺寸；明确是否为真实工程 | 图题与用途一致，不把教学图作为施工图 |
| 整理已知量 | 列跨度、桥宽、梁距、板厚、横隔位置、轮距、支承形式；逐项标来源与单位 | 无依据尺寸留待核；不从一张透视照片自动补成真实值 |
| 建立基准 | 坐标、中心线、标高、单位与已知控制尺寸 | 横纵两个方向校核，排查扫描变形和错误缩放 |
| 重建几何与语义 | 主梁、桥面、横隔、支座、尺寸、文字分层；必要处使用参数约束 | 视觉接触不代替连接关系，空洞、缝隙、端部与连续部位明确 |
| 自动出图 | 按教学模型生成SVG/TikZ或CAD，数值由计算源写入；再导出出版PDF及网页SVG | 标签与图形同步，无手工改数造成两套答案 |
| 复核 | 尺寸链、剖面、构件数量与位置、箭头、单位、荷载方向和未变形参照逐项核对 | 输出尺寸抽测、叠图或对照表、复核人及日期 |
| 留源文件 | 保存参数表、脚本、可编辑模型和输出版本 | 图可重建；截图不能代替源模型 |

对弯矩图、影响线、振型、变形云图，主数据先经解析/数值检查，再绘制。AI可提案或辅助写脚本，不能凭图像生成“看似合理的曲线”。对结构细部，CAD精确并不等于结构正确，构件连接与受力解释仍要人工复核。

## 6. 每张图的执行流程与验收字段

**选图 → 记录出处 → 决定原用/授权改编/独立重建 → 制作 → 专业复核 → 编校与许可复核 → 进入出版版。** 待核图保留在候选清单中；正式学生网页与出版稿只采用状态明确的版本。原图不适用时继续以文字问题和已核实数据制作独立图解，不以去水印或换风格替代核权。

| 字段组 | 必填记录 |
|---|---|
| 对象 | 图ID、章节落点、教学问题、图题、照片/示意/计算结果/CAD分类 |
| 原始来源 | 作者/机构、题名、原发布链接、原文件标识、核查日期；原图来自书时记录版本、页码与图号 |
| 权利依据 | 许可全称与版本、许可链接/授权文件、公有领域依据、权利人身份；待核项不能填“网络公开” |
| 使用范围 | 纸书、PDF、网页、课程视频分别核对；是否允许修改、翻译标注、署名方式、有效期及地域 |
| 制作路径 | 原用/格式转换/授权改编/独立绘制/AI辅助；参考图、提示词、工具/模型版本、人工改动 |
| 工程依据 | 尺寸与单位来源、计算模型、数据/脚本版本、假定、变形放大、纪实/示意身份 |
| 输出 | 可编辑源文件、SVG/PDF/位图版本、最终版面尺寸下的可读性与清晰度、替代文本 |
| 复核 | 专业复核人、编校/许可复核人、日期、问题及处理、对应输出版本 |
| 状态 | 候选待核／可按原许可使用／可按授权改编／独立绘制待复核／已确认用于指定版本／不采用 |

最小验收动作：打开原许可核对用途；从图中抽查一个尺寸和一个物理量；检查照片/示意身份；从源文件重出一次图；以实际出版尺寸查看标签与线宽；最后确认图注、资源台账与输出版本一致。**画得清楚、算得正确、可以出版是三项分别有证据的检查。**
